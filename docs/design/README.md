# Design mockups

The reference screens for spec 09 (styling), direction "B · La cinta de carrocero". Each screen is here twice:

- `N-name.png`: the picture to compare the built app against, at iPhone width (390 px, 2x).
- `N-name.html`: the same mockup as a static page, with the exact colours, sizes and fonts. Open it in a browser at 390 px wide.

| File | Screen |
| --- | --- |
| `1-nueva-ficha` | Record screen at rest, before recording |
| `2-grabando` | Recording, with the timer and the steps |
| `3-ficha-sin-confirmar` | The sheet just created from a voice note, before confirming |
| `4-ficha-linea-abierta` | The same sheet with one line open for editing |
| `5-preparaciones` | The list of saved preparations |
| `6-ficha-guardada` | A saved sheet, read-only |

Costs, prices and the "% estimado" share in these mockups are example data. They arrive with specs 06 and 07; until then the screens show quantities only.

Source: the Design canvas on claude.ai (https://claude.ai/artifact/1EXpL5vayJdSi88sqRBvzu, page "Ronda 2"), exported on 2026-11-15. If the canvas changes, export the screens again so this folder stays the reference.
